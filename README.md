# mhime-studylog01
6年1組のための学習ログアプリです。

## 使い方

学習日、科目、本時の課題、目標、学習方法、評価、振り返りを入力して保存できます。保存した記録はブラウザの `localStorage` に保持され、科目や期間で絞り込んだり、学習方法の集計や評価の変化を確認したりできます。

外部ライブラリを使わない静的サイトです。ローカルで確認する場合は、リポジトリのルートで次のコマンドを実行し、`http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```

## ファイル構成

- `index.html`: 学習ログ画面
- `styles.css`: 画面の配色とレイアウト
- `app.js`: 保存、編集、削除、絞り込み、集計
- `image.png`: アプリ用画像
